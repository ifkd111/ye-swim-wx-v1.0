# 叶 微信小程序

这是“叶”的纯消课微信小程序：

- 老板：维护教练、学员和总课时，查看当天流水，并可补录、修改或撤销。
- 教练：每天打开首页展示固定二维码，供家长扫码消课。
- 家长/学员：微信扫码后选择到场孩子和 1/2/3 节，确认后查看余额。

## 当前能力清单

- 每位教练每天一张固定小程序码，可截图或转发给家长；老板本人也有教练码。
- 老板拥有长期教练登记码 A 和学员登记码 B，可发到群里让人员自行分类扫码。
- 教练只需授权微信手机号；家长可一次登记多名孩子并分别填写剩余课时。
- 所有扫码登记都必须由老板确认；老板可修正姓名和课时，微信验证手机号只读且不可修改。
- 一个家长手机号可绑定多个孩子，扫码页默认全选并允许移除未到场孩子。
- 家长每次只能选择每人扣 1、2、3 节；同一学员同日同教练默认禁止重复扫码。
- 允许剩余课时为负数，并在老板和家庭端明确显示欠课。
- 老板可补录任意 1 至 99 节、修改扣课、撤销返还，并留下审计信息。
- 课程统一为总课时、已上课时、剩余课时，不再展示课程产品、预约、排课或请假流程。
- 教练和家长在正式版使用微信手机号一键验证，系统自动识别身份。
- 老板可通过二维码、Excel/WPS 表格或手动输入录入人员；表格导入会先预检再确认写入。
- 微信资料仅保存用户自愿设置的头像和昵称，不读取真实微信号。

## CI 上传

CI 上传需要微信公众平台的“代码上传密钥”，不是 AppSecret。

1. 到微信公众平台 `开发管理 / 开发设置` 下载代码上传密钥。
2. 建议保存到本地私有备份目录，并在上传时用 `--key=密钥路径` 指定；如保存为项目根目录 `private.key`，这个文件已被 `.gitignore` 忽略，不会提交。
3. 如平台要求 IP 白名单，先按页面提示配置本机公网 IP，或临时关闭 IP 白名单限制。最近一次 CI 出口为 `116.230.254.62`；如网络或代理变化，请以报错中的 `invalid ip` 为准重新填写。

常用命令：

```powershell
npm run ci:preview
npm run ci:upload -- --key=你的代码上传密钥路径 --uv=2.1.9 --ud=v2.1.9三角色体验、异常恢复与触控优化
$env:YE_SWIM_SEED_SECRET="请替换为随机长密钥"
npm run ci:upload-function -- --key=你的代码上传密钥路径 --env=cloudbase-d6ge373q7724bcfe4
npm run migrate:v1.3 -- --env=cloudbase-d6ge373q7724bcfe4
npm run ci:quality
```

当前 `2.1.9` 在开发版、体验版和正式版均使用真实微信云开发环境；远端 GitHub 和 tag 发布后按发布记录同步。

## 登录与鉴权

- 正式环境老板账号应通过种子数据或受控初始化创建；不会因有人尝试公开默认口令而自动恢复密码。
- 老板、教练和家长共用一个微信手机号登录入口，云端按老板预先登记的手机号自动识别身份并进入对应首页。
- 老板首次授权已登记手机号时绑定当前微信；以后直接无感进入老板端。同一老板手机号在新微信重新验证后可安全换绑。
- 老板手机号加密码仅作为隐藏的审核与应急入口；`yeats` 只保留为内部兼容标识，正常登录界面不展示。
- 教练和家长只允许微信手机号验证登录，账号密码入口不能绕过手机号验证。
- 老板可在账号页解除教练/学员的旧微信绑定。
- mock 示例账号仍用于本地自动测试，不应当作为生产凭据。

云函数上传和种子导入必须显式设置随机长密钥 `YE_SWIM_SEED_SECRET`。`YE_SWIM_ALLOW_ADMIN_BOOTSTRAP` 和 `YE_SWIM_ENABLE_TEST_LOGIN` 均默认关闭，仅在受控应急或开发环境临时开启。

# 叶 微信小程序

这是“叶”的微信小程序版本，主打手机端使用：

- 管理员老板：审批预约、排课、学员新增修改、账号管理、批量导入、扫码核销。
- 教练：本周排课、确认出勤、扫码核销、我的学员、可编辑空余时间助手。
- 学员：查看课时、推荐预约、本周课程、消课记录、课程申请和上课二维码。

## 当前能力清单

- 三角色账号体系：管理员、教练、学员按账号前缀自动进入对应工作台。
- 预约闭环：教练提交空余，管理员发布，学员预约，管理员审批后生成正式排课。
- 出勤与课消：教练或管理员确认出勤，系统按课程类型扣课时。
- 二维码核销：学员端可查看课程二维码，教练或管理员扫码后完成核销，防止重复核销。
- 经营提醒：管理员首页展示预约审批、续课申请、低课时风险和今日课程。
- 学员体验：学员首页展示账户信息、当前课程、剩余课时、下一节课、课程申请和记录入口。

## CI 上传

CI 上传需要微信公众平台的“代码上传密钥”，不是 AppSecret。

1. 到微信公众平台 `开发管理 / 开发设置` 下载代码上传密钥。
2. 建议保存到本地私有备份目录，并在上传时用 `--key=密钥路径` 指定；如保存为项目根目录 `private.key`，这个文件已被 `.gitignore` 忽略，不会提交。
3. 如平台要求 IP 白名单，先按页面提示配置本机公网 IP，或临时关闭 IP 白名单限制。本机曾检测到 `116.230.254.110` 和 `212.87.195.173` 两条出口；如网络或代理变化，请重新查询公网 IP 后再填。

常用命令：

```bash
npm run ci:preview
npm run ci:upload -- --key=你的代码上传密钥路径 --uv=1.2.0 --ud=v1.2.0二维码核销与学员端体验升级
npm run ci:upload-function -- --key=你的代码上传密钥路径 --env=cloudbase-d6ge373q7724bcfe4
npm run ci:quality
```

当前 `1.2.0` 使用真实微信云开发环境；远端 GitHub 和 tag 发布后按发布记录同步。

# 叶 微信小程序

这是“叶”的微信小程序版本，主打手机端使用：

- 管理员老板：查看每日教练供给与学员需求，调整自动课程草稿并决定发布。
- 教练：在日程中批量提交空闲时间、确认出勤、扫码核销和填写课后反馈。
- 学员：从课程日历按地点、课程、教练时间完成挂号式预约，并查看课时与上课码。

## 当前能力清单

- 三角色账号体系：管理员、教练、学员按账号前缀自动进入对应工作台。
- 预约闭环：老板开放教练时间，学员选择后自动生成课程草稿；老板调整或发布后才生成正式排课。
- 出勤与课消：教练或管理员确认出勤，系统按课程类型扣课时。
- 二维码核销：学员端可查看课程二维码，教练或管理员扫码后完成核销，防止重复核销。
- 手机号登录：老板维护教练/学员手机号，教练和学员通过微信手机号验证绑定登录。
- 经营提醒：管理员首页展示预约审批、续课申请、低课时风险和今日课程。
- 老板排课：每周固定模板云端保存，生成下周预览后一键发布；临时课程可单独增加，已发布时间可停止继续预约。
- 经营看板：管理员可查看近 7/30 天完成课程、消课、请假补课和教练排行。
- 课后反馈：教练或管理员核销后可补充标签和备注，学员端可查看成长记录。
- 请假补课：学员提交请假，老板审批后生成补课额度并安排补课。
- 学员体验：学员首页就是课程日历，已排课程显示教练和地点，空白日期可直接开始预约。
- 教练现场：教练首页可直接扫码、确认出勤并填写课后反馈，无需先进入排课列表。

## CI 上传

CI 上传需要微信公众平台的“代码上传密钥”，不是 AppSecret。

1. 到微信公众平台 `开发管理 / 开发设置` 下载代码上传密钥。
2. 建议保存到本地私有备份目录，并在上传时用 `--key=密钥路径` 指定；如保存为项目根目录 `private.key`，这个文件已被 `.gitignore` 忽略，不会提交。
3. 如平台要求 IP 白名单，先按页面提示配置本机公网 IP，或临时关闭 IP 白名单限制。最近一次 CI 出口为 `116.230.254.62`；如网络或代理变化，请以报错中的 `invalid ip` 为准重新填写。

常用命令：

```powershell
npm run ci:preview
npm run ci:upload -- --key=你的代码上传密钥路径 --uv=1.4.1 --ud=v1.4.1老板端教练与学员管理重构
$env:YE_SWIM_SEED_SECRET="请替换为随机长密钥"
npm run ci:upload-function -- --key=你的代码上传密钥路径 --env=cloudbase-d6ge373q7724bcfe4
npm run migrate:v1.3 -- --env=cloudbase-d6ge373q7724bcfe4
npm run ci:quality
```

当前 `1.4.1` 使用真实微信云开发环境；远端 GitHub 和 tag 发布后按发布记录同步。

## 登录与鉴权

- 正式环境老板账号应通过种子数据或受控初始化创建；不会因有人尝试公开默认口令而自动恢复密码。
- 教练和学员只允许微信手机号验证登录，账号密码入口不能绕过手机号验证。
- 所有已登录业务请求都会重新校验当前微信 `openid`；老板可在账号页解除教练/学员的旧微信绑定。
- mock 示例账号仍用于本地自动测试，不应当作为生产凭据。

云函数上传和种子导入必须显式设置随机长密钥 `YE_SWIM_SEED_SECRET`。`YE_SWIM_ALLOW_ADMIN_BOOTSTRAP`、`YE_SWIM_ALLOW_ADMIN_REBIND` 和 `YE_SWIM_ENABLE_TEST_LOGIN` 均默认关闭，仅在受控应急或开发环境临时开启。

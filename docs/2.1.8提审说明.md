# 2.1.8 提审说明

## 审核体验路径

1. 打开小程序后直接进入免登录功能体验首页，不会弹出或要求授权手机号、头像、昵称。
2. 首页可直接点击“家长扫码消课”“教练上课码”“老板今日记录”三个板块体验核心功能。
3. 在“家长扫码消课”中，可选择示例学员、分别选择扣 1/2/3 节并完成模拟确认。该流程仅使用脱敏本地演示数据，不读取个人信息，也不会写入正式课时。
4. 体验完成后，用户可自主点击“登录我的账号”或“登录查看我的课时”，再选择微信手机号授权。
5. 手机号授权页面提供“暂不登录，继续体验功能”，用户拒绝授权后可返回并继续使用免登录体验。

## 建议填写的提审备注

本版本已根据上次审核意见整改。首次打开即进入可操作的免登录功能体验首页，不要求手机号、头像或昵称授权。审核员可直接切换并体验家长扫码消课、教练每日码、老板今日记录；家长体验还可选择不同学员和 1/2/3 节后完成本地模拟确认。体验数据均为脱敏本地示例，不读取个人信息、不写入正式数据。只有用户体验后主动点击登录按钮时才会申请微信手机号授权，且授权页提供“暂不登录，继续体验功能”的明确返回选项。头像和昵称并非登录必填项，进入正式账号后仍由用户自愿设置。

# 版本记录

## v1.0.8

- 修复管理员登录时触发大批量种子数据导入导致的手机端报错。
- 登录只做账号校验和轻量管理员兜底，真实名单改为本机脚本分批导入云数据库。
- 管理员 `yeats / 1324` 可重新绑定当前微信，避免老板账号被旧测试设备锁住。
- 云函数包排除本地种子大文件，降低上传和冷启动压力。
- 新增 `npm run ci:seed-cloud -- --env=cloudbase-d6ge373q7724bcfe4` 用于导入 Excel 生成的真实账号、学员、排课、出勤数据。

## v1.0.7

- 全局 UI 改为蓝白配色，红色仅用于危险和异常提醒。
- 修复移动端顶部标题被按钮挤压成竖排的问题，卡片、表单和筛选按钮改为更稳的 flex 布局。
- 修复云函数中业务 `id` 与云数据库 `_id` 不一致导致的预约、审批、出勤、发布空余时间断链问题。
- 从 `出勤测试(2).xlsx` 生成上线起手数据：6 个教练账号、349 个学员账号、1367 条排课和 1367 条出勤记录。
- 生成本地私有账号清单 `private-output/ye-swim-wx-accounts.csv`，默认密码：管理员 `1324`，教练和学员 `1234`。
- 增加自动流程测试，覆盖管理员、教练、学员核心闭环。

## v1.0.6

- 切换到真实微信云开发环境 `cloudbase-d6ge373q7724bcfe4`。
- 默认关闭 mock 数据，手机体验版将通过云函数 `api` 读写云数据库。
- 云函数加入空库自动初始化，首次 `yeats / 1324` 登录会写入示例账号、学员、排课和出勤数据。
- 更新小白启动说明和上传命令，准备真实云数据库联调。

## v1.0.5

- 管理员账号改为 `yeats`，默认密码保留 `1324`。
- 教练和学员默认密码改为 `1234`。
- 管理员账号页支持创建账号、绑定教练/学员，并可一键重置账号默认密码。
- 教练、学员和管理员都可在自己的工作台修改自己的密码；账号名只能由管理员创建绑定，不能自行修改。

## v1.0.4

- 教练端“常用按钮”改为可编辑模板，教练可新增、修改、删除自己的常用空余规则。
- 教练工作台数字卡片可点击，“我的学员”进入已分配学员列表，“待确认/本周课程/已安排课程”进入排课页。
- 教练排课页支持本周、待确认、已完成、全部筛选，并可直接确认出勤。
- 学员首页把“剩余课时”和“预约课程”合并为主入口，减少按钮占用。
- 学员“已消课”改为可点击入口，直接进入消课记录，显示日期、教练、校区和扣课数。
- 学员近期课程改为展示未来 7 天的本周课程。

## v1.0.3

- 教练端“提交空余”升级为“空余助手”，支持一句话生成、常用快捷按钮、记忆默认校区/名额/课时、预览后批量提交。
- 教练可快速生成“明天下午”“明天全天”“下周每天下午”等空余时间。
- 新增 `createAvailabilitySlots` 批量空余时间动作；教练提交仍默认草稿，老板决定是否发布。
- 学员预约页增加推荐预约、明天起/本周/周末筛选、点击确认弹窗。
- 学员端隐藏复杂规则细节，优先展示最容易预约的时间。

## v1.0.2

- 老板首页数字卡片和预约卡片改为可点击入口，直接进入审批、排课、学员和账号。
- 学员页支持新增、修改和备注名维护。
- 账号页支持新增、修改账号，继续按 `yeats` / `jl*` / `xy*` 自动分配角色。
- 增加“批量导入”页，支持复制名单后预览并导入学员。
- 云函数补齐 `saveMember`、`bulkImportMembers`、`saveAccount`，并统一返回 `id` 供页面按钮使用。

## v1.0.1

- 登录页移除角色选择按钮，只保留账号密码入口。
- 登录后按 `yeats` / `jl*` / `xy*` 自动进入管理员、教练、学员工作台。
- 品牌统一为单字“叶”，并优化登录页单字 logo。
- 记录 `gh`、微信开发者工具和本机自动化端口状态。

## v1.0.0

- 新建“叶”微信小程序独立项目。
- 支持管理员、教练、学员三角色。
- 支持账号密码首次登录绑定微信。
- 支持学员预约、管理员审批生成排课、教练确认出勤。
- 支持微信云开发数据库和 mock 模式。
- 提供 seed 导出、项目校验和规则测试脚本。

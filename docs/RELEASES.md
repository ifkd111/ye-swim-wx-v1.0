# 版本记录

## v1.0.2

- 老板首页数字卡片和预约卡片改为可点击入口，直接进入审批、排课、学员和账号。
- 学员页支持新增、修改和备注名维护。
- 账号页支持新增、修改账号，继续按 `admin` / `jl*` / `xy*` 自动分配角色。
- 增加“批量导入”页，支持复制名单后预览并导入学员。
- 云函数补齐 `saveMember`、`bulkImportMembers`、`saveAccount`，并统一返回 `id` 供页面按钮使用。

## v1.0.1

- 登录页移除角色选择按钮，只保留账号密码入口。
- 登录后按 `admin` / `jl*` / `xy*` 自动进入管理员、教练、学员工作台。
- 品牌统一为单字“叶”，并优化登录页单字 logo。
- 记录 `gh`、微信开发者工具和本机自动化端口状态。

## v1.0.0

- 新建“叶”微信小程序独立项目。
- 支持管理员、教练、学员三角色。
- 支持账号密码首次登录绑定微信。
- 支持学员预约、管理员审批生成排课、教练确认出勤。
- 支持微信云开发数据库和 mock 模式。
- 提供 seed 导出、项目校验和规则测试脚本。

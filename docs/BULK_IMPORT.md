# 批量添加学员

## v1.0.2 已支持

在老板工作台点“批量导入”，把名单复制进去，点“预览名单”，确认无误后点“确认导入”。

推荐每行一个学员：

```text
姓名 手机 校区 教练 总课时
白卓可 13800000000 绿洲 绿洲教练 26
白卓冉
饼饼 古北 古北教练 20
```

只填姓名也可以，系统会用页面上方的默认校区、默认教练、默认课程和默认课时。

## 为什么先做粘贴导入

微信小程序可以从聊天记录选择 Excel/CSV，也可以拍照上传图片；但为了避免用户上传错表、错列或识别错字，正式产品里应走这个流程：

1. 选择文件、拍照或粘贴名单。
2. 系统识别成预览表。
3. 用户在预览表里改错。
4. 点确认后才写入数据库。

所以 v1.0.2 先落最稳的“粘贴名单 -> 预览 -> 确认导入”。后续可以在同一页加“拍照识别”和“微信文件导入”，底层仍然复用同一个 `bulkImportMembers` 云函数。

# 「叶」课程小程序交付与分发说明

适用版本：v1.4.3

## 一、这个小程序用来做什么

这是一个面向老板、教练和学员的课程安排与消课工具：

- 老板维护教练、学员和手机号，查看每天教练空闲与学员上课需求，确认并发布课程。
- 教练提交空闲时间、查看自己的课程，并扫描学员上课码完成消课。
- 学员查看课程日历、选择希望上课的时间，并在首页展示上课二维码。

课程申请会自动生成待发布草稿，但不会自动发布，最终由老板决定是否发布或调整。

## 二、正式分发前

当前交付代码版本为 v1.4.3。向所有教练和学员正式分发前，需要确认微信公众平台中的该版本已经完成审核并发布。

如果版本仍显示在“开发版本”中：

1. 登录微信公众平台。
2. 打开“管理 → 版本管理”。
3. 找到 v1.4.3，提交微信审核。
4. 审核通过后点击“发布”；如果已经开启审核后自动发布，则等待平台完成发布即可。
5. 用普通微信账号打开小程序，确认首页和版本无误后再发到群里。

开发版或体验版只能供已添加的开发者、体验成员使用，不能代替正式发布版向所有人分发。

## 三、老板首次设置

请先完成教练和学员资料，再让大家登录。

### 添加教练

1. 老板登录小程序。
2. 首页点击“教练”或“教练与登录”。
3. 点击“新增教练”。
4. 填写教练姓名、真实手机号并选择主要校区。
5. 点击“保存教练”。

保存后状态显示“待首次登录”。教练第一次用该手机号验证成功后，状态会变为“微信已绑定”。

### 添加学员

1. 老板首页进入“学员管理”。
2. 点击“新增”。
3. 填写学员姓名和真实手机号。
4. 点击选择上课地点、教练和课程，并确认总课时。
5. 点击“保存学员”。

一个手机号只能绑定一个小程序身份。请勿把同一个手机号同时登记给两名学员或不同角色。

## 四、如何分发给教练和学员

正式发布后，老板可以直接打开小程序，点击微信右上角“…”并选择“转发”，把小程序卡片发送给教练、学员或微信群。

建议先完成手机号登记，再发送小程序。收到小程序的人不需要老板提供账号或密码。

### 可直接发给教练的话

> 这是我们后续使用的课程小程序。请打开后选择“手机号登录”，输入我为你登记的手机号，再点击“微信验证并进入”。系统会自动进入教练界面。以后请在里面提交空闲时间、查看课程；上课后点击“扫码核销”，扫描学员首页展示的上课码完成消课。首次扫码请允许使用摄像头。

### 可直接发给学员的话

> 这是我们后续使用的课程小程序。请打开后选择“手机号登录”，输入报名时登记的手机号，再点击“微信验证并进入”。系统会自动进入学员界面。你可以在首页查看课程和剩余课时，按“地点 → 课程 → 教练时间”选择希望上课的时间。上课时点击日历右上角“展示上课码”，把二维码出示给教练即可。

## 五、日常使用顺序

1. 教练提交自己可上课的日期、时间和地点。
2. 学员在日历中选择日期、地点、课程和教练空闲时间，并确认提交。
3. 老板首页查看“教练有空”和“学员想上课”，系统自动生成课程草稿。
4. 老板检查教练、地点和时间，可以临时调整，然后决定发布。
5. 发布后，课程显示在教练和学员各自首页。
6. 上课时学员点击“展示上课码”，教练点击“扫码核销”。
7. 核销成功后自动记录消课，教练可以填写课后反馈。

## 六、常见问题

### 提示“手机号未开通账号”

老板还没有登记该手机号，或登记号码有误。请老板在教练/学员管理中核对。

### 提示“微信授权手机号与输入号码不一致”

输入的手机号必须与微信验证得到的手机号一致，也必须与老板登记的号码一致。

### 提示“已经绑定其他微信”

老板进入对应教练或学员资料，点击“解除微信绑定”。本人再用登记手机号重新验证。

### 修改了手机号

老板保存新手机号后，旧微信绑定会自动失效；本人需要使用新手机号重新验证。

### 教练无法使用摄像头扫码

重新点击“扫码核销”，按提示进入微信设置并开启相机权限，授权后会自动继续扫码。

### 学员首页没有可展示的上课码

只有老板已经发布、尚未核销且仍在有效期内的课程才会生成可使用的上课码。待发布草稿、已请假、已取消、已核销或已过期课程不能继续使用。

### 扫码后提示不能核销

教练只能核销安排给自己的课程；已经核销、已过期或不属于该教练的课程都会被系统阻止。

## 七、老板需要记住的三件事

1. 先绑定正确手机号，再让教练和学员登录。
2. 系统只自动生成课程草稿，是否发布始终由老板决定。
3. 更换手机号或微信时，及时修改手机号或解除旧微信绑定。

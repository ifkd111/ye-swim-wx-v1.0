# 「叶」纯消课小程序交付与分发说明

适用版本：v2.0.0

## 这个小程序做什么

- 老板：添加教练和学员、绑定手机号、管理总课时，查看、补录、修改或撤销消课流水。
- 教练：每天打开首页展示自己的固定教练码；老板本人带课时也使用老板首页的今日码。
- 家长：到场后用微信“扫一扫”扫描教练码，选择到场孩子和每人扣除的 1、2、3 节，确认后立即完成消课。

约课、排课和上课时间继续由老板在线下、电话或微信中沟通，小程序不再处理。

## 正式分发前

v2.0.0 已上传为开发版本。老板需要登录微信公众平台，在“管理 → 版本管理”找到 v2.0.0，提交审核；审核通过后点击“发布”。开发版和体验版只能供开发者或体验成员使用，不能代替正式发布版。

正式发布后，老板打开小程序，点击微信右上角“…”并选择“转发”，即可把小程序卡片发给教练、家长或微信群。

## 老板首次设置

### 添加教练

1. 老板首页点击“教练”。
2. 点击“新增教练”。
3. 填写姓名和真实手机号并保存。
4. 教练第一次使用微信手机号验证后，状态会显示“微信已绑定”。

### 添加学员

1. 老板首页点击“学员课时”。
2. 点击“新增学员”。
3. 填写学员姓名、家长手机号和总课时并保存。
4. 同一个家长手机号可以继续添加第二个、第三个孩子，系统会放在同一个家庭账号中。
5. 后续续费时，在学员列表点击“加课 / 调整总课时”。

## 可直接转发的话

发给教练：

> 请打开“叶”小程序，点击微信手机号验证。以后上课时打开首页，把当天的“今日教练码”给家长扫描即可。当天二维码固定不变，可以截图或转发。

发给家长：

> 请打开“叶”小程序并使用报名手机号完成微信验证。到场上课时，用微信“扫一扫”扫描教练手机上的今日码，核对孩子和扣课节数后确认。首页可以随时查看总课时、已上课时和剩余课时。

## 日常使用

1. 教练打开首页展示今日教练码。
2. 家长用微信扫一扫；未登录时先一键验证手机号。
3. 多个孩子默认全部选中，没到场的点一下移除。
4. 选择每名孩子扣 1、2 或 3 节，确认后立即扣课。
5. 同一孩子同一教练同一天默认不能重复扫码。
6. 少扣、漏扫或误扣时，由老板在首页修改、补录或撤销。
7. 课时用完仍可消课，余额会显示为“欠课”，老板之后补加总课时即可。

## 常见问题

### 手机号未开通

老板尚未登记该手机号，或号码填写有误。请在教练或学员管理中核对。

### 已绑定其他微信

老板在教练资料中点击“解除微信”；家长账号如需更换微信，由老板核对身份后处理绑定。

### 扫码提示当天已经消课

系统正在防止重复扣课。如果确实多上了一节，由老板修改原流水的课时；不要重复扫码。

### 只有一个孩子到场

扫码确认页默认勾选同一家庭的所有孩子，点击未到场孩子即可移除。

### 没带手机

当天教练码可以截图或转发给家长，由家长在自己的微信中扫描确认。

## 老板记住三件事

1. 先登记正确手机号，再让教练和家长登录。
2. 家长扫码负责日常消课，异常情况由老板纠错。
3. 开发版本必须完成微信审核并发布后，普通用户才能使用。

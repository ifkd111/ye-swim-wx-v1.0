# 「叶」纯消课小程序交付与分发说明

适用版本：v2.1.3

## 这个小程序做什么

- 老板：把教练登记码 A、学员登记码 B 发到群里，审核并修正姓名和课时；也可管理课时、补录、修改或撤销消课流水。
- 教练：每天打开首页展示自己的固定教练码；老板本人带课时也使用老板首页的今日码。
- 家长：到场后用微信“扫一扫”扫描教练码，选择到场孩子和每人扣除的 1、2、3 节，确认后立即完成消课。

约课、排课和上课时间继续由老板在线下、电话或微信中沟通，小程序不再处理。

## 正式分发前

v2.1.3 上传为开发版本后，老板需要登录微信公众平台，在“管理 → 版本管理”找到 v2.1.3，提交审核；审核通过后点击“发布”。开发版和体验版只能供开发者或体验成员使用，不能代替正式发布版。

正式发布后，老板打开小程序，点击微信右上角“…”并选择“转发”，即可把小程序卡片发给教练、家长或微信群。

## 老板首次设置

### 让教练自行登记

1. 老板首页点击“自助登记”，把教练登记码 A 发到教练群。
2. 教练扫码并授权微信手机号，不需要填写其他资料。
3. 老板在“等待你确认”中打开申请，填写或修正教练姓名，再点击“确认并开通”。
4. 教练之后直接从登录页授权同一手机号进入，不必再次扫描登记码。

### 让家长自行登记学员

1. 老板首页点击“自助登记”，把学员登记码 B 发到家长群。
2. 家长扫码，可一次添加多个孩子，并分别填写姓名和当前剩余课时。
3. 老板打开申请，核对并修正每名孩子的系统姓名和剩余课时，再点击“确认并开通”。
4. 家长之后直接从登录页授权同一手机号进入；一个手机号下会显示全部孩子。
5. 微信验证手机号只可查看，不能修改；后续续费仍在学员列表点击“加课 / 调整总课时”。

登记码 A、B 可长期反复使用。如果二维码泄露或不想继续接收旧码申请，老板可点“更换”，旧码会立即失效。

## 可直接转发的话

发给教练：

> 请扫描教练登记码 A，并授权微信手机号。老板确认后，你从“叶”小程序登录页授权同一手机号即可进入。以后上课时打开首页，把当天的“今日教练码”给家长扫描即可。

发给家长：

> 请扫描学员登记码 B，填写孩子姓名和当前剩余课时；双胞胎可以一次添加。老板确认后，从“叶”小程序登录页授权同一手机号即可进入。到场上课时，再扫描教练手机上的今日码完成消课。

## 日常使用

1. 教练打开首页展示今日教练码。
2. 家长用微信扫一扫；未登录时先一键验证手机号。
3. 多个孩子默认全部选中，没到场的点一下移除。
4. 选择每名孩子扣 1、2 或 3 节，确认后立即扣课。
5. 同一孩子同一教练同一天默认不能重复扫码。
6. 少扣、漏扫或误扣时，由老板在首页修改、补录或撤销。
7. 课时用完仍可消课，余额会显示为“欠课”，老板之后补加总课时即可。

## 常见问题

### 手机号未开通

老板尚未登记该手机号，或号码填写有误。请在教练或学员管理中核对。

### 已绑定其他微信

老板在教练资料中点击“解除微信”；家长账号如需更换微信，由老板核对身份后处理绑定。

### 扫码提示当天已经消课

系统正在防止重复扣课。如果确实多上了一节，由老板修改原流水的课时；不要重复扫码。

### 只有一个孩子到场

扫码确认页默认勾选同一家庭的所有孩子，点击未到场孩子即可移除。

### 没带手机

当天教练码可以截图或转发给家长，由家长在自己的微信中扫描确认。

## 老板记住三件事

1. 把 A 码发给教练、B 码发给家长，并及时审核待确认申请。
2. 家长扫码负责日常消课，异常情况由老板纠错。
3. 开发版本必须完成微信审核并发布后，普通用户才能使用。
